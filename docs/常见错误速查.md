# 常见错误速查表

> 学生第一天最常问的问题都在这里。建议印出来贴在显示器边上。

---

## 编译期错误

### 1. `undefined reference to 'xxx'`

```
/usr/bin/ld: /tmp/ccXXXX.o: in function `main':
yourfile.c:(.text+0x...): undefined reference to `sqrtf'
collect2: error: ld returned 1 exit status
```

**原因**：用了数学函数但忘了链接数学库。
**解决**：`-lm` 放在**编译命令的最后面**。

```bash
# ❌ 错
gcc -lm -o yourprog yourfile.c
# ✅ 对
gcc -o yourprog yourfile.c -lm
```

---

### 2. `implicit declaration of function 'xxx'`

```
warning: implicit declaration of function 'sqrtf'
```

**原因**：忘了 `#include <math.h>`。
**解决**：加上头文件。

```c
#include <math.h>
```

---

### 3. `error: expected ';' before ...`

**原因**：上一行漏了分号。
**排查方法**：gcc 报的错在**下一行**，真正的错误在**上一行**末尾。

---

### 4. `warning: unused variable 'xxx'`

**原因**：声明了变量但没用。不影响运行，但说明代码有问题。
**解决**：删掉，或者真的用上它。

---

## 运行期错误

### 5. `Segmentation fault (core dumped)` 段错误

**99% 的情况是内存出错了**，按下面顺序排查：

| 可能原因 | 怎么检查 | 怎么修 |
|---|---|---|
| 数组越界 | 看下标有没有 `>= 数组长度` | 加边界判断 |
| 空指针解引用 | 打印 `%p` 看是不是 `NULL`/`(nil)` | 加 `if (p == NULL) return;` |
| 内存泄漏后耗尽 | 用 `valgrind` | 加 `free()` |
| 释放后继续用 | 用 `valgrind` | 把 `free` 后的指针置 `NULL` |
| 栈溢出（递归太深） | 递归深度是不是太大 | 改成循环 |

**必备武器：**
```bash
valgrind --leak-check=full ./day04_pointer
```
valgrind 会精确告诉你"哪一行分配了没释放的内存"。

**调试打印技巧：**
```c
printf("[DEBUG] ptr=%p, value=%f\n", (void*)p, *p);
```
先确认指针不是 `NULL`，再解引用。

---

### 6. `Floating point exception` 浮点异常

**原因**：整数除法除以了 0。
**排查**：搜索所有除法，看分母可能是 0 的地方。

```c
int bmi = weight / (height * height);   // height == 0 就崩
```

---

### 7. 输出是乱码 / 模型不生成正常文本

按顺序检查：

| 检查项 | 命令 | 预期 |
|---|---|---|
| 模型文件完整 | `ls -l data/stories15M.bin` | `60816028` 字节 |
| 分词器路径正确 | `ls -l data/tokenizer.bin` | `433869` 字节 |
| 参数传对 | `./bin/day14_llama2 data/stories15M.bin -z data/tokenizer.bin -i "hi"` | 有故事文本 |
| 温度不是 0 | 加上 `-t 1.0` | 不复读 |

**最常见的原因**：忘了 `-z data/tokenizer.bin`，程序在当前目录找 `tokenizer.bin` 找不到。

---

### 8. 输出重复同一个词，停不下来

**原因**：`temperature = 0`（贪心解码）导致复读。
**解决**：用 `-t 1.0 -p 0.9`。

> 这不是 bug，这是贪心解码的固有行为，Day 13 会讲原理。

## 概念类问题

### 9. 为什么 `scanf("%d", n)` 会崩？

`scanf` 需要知道"把值写到哪里"，也就是需要一个**地址**。
`int n;` 时 `n` 是值，必须写 `&n` 取地址。
（`char s[20]` 可以不加 `&`，因为数组名本身就是首元素地址。）

### 10. 为什么 `float a[100]` 传进函数后 `sizeof(a)` 变成 4？

函数参数里的数组会**退化成指针**，`sizeof` 算的是指针大小（64 位下是 8 字节）。
要拿到元素个数，必须额外传一个 `n`：

```c
void f(float *a, int n) { ... }   // 正确
```

### 11. 为什么权重矩阵存成 `(out, in)` 而不是 `(in, out)`？

因为 `matmul` 的内层循环是遍历 `j`（输入维度），
`(out, in)` 布局下 `w[i*n+j]` 在 `i` 固定时 `j` 连续 → **cache 友好**。
Day 7 会用实测数据证明这一点。

### 12. 为什么链接顺序是 `.c -lm`？

`-lm` 是给**链接器**看的，链接器从左到右处理。
如果先看到 `-lm` 还没有需要用它的目标文件，就会报 `undefined reference`。
